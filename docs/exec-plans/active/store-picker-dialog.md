# 予約CTAから店舗選択ダイアログを開く

- **Started:** 2026-09-01
- **Rule:** [docs/exec-plans/README.md](../README.md)
- **Completed path:** `docs/exec-plans/completed/store-picker-dialog.md`

## Goal

3か所の予約CTAを押すと、店舗を選ぶダイアログが開く。エリアで絞り込み、店舗ごとの
LINE予約へ進める。いまは3つとも公式HPのトップに飛ばしていて、来訪者が自分の店舗を
自力で探し直している。

## Scope

- [x] `<dialog>` で店舗選択を実装（`index.html`）
- [x] エリアタブ（関西・名古屋・福岡 / 東京）で絞り込み
- [x] LPの誌面デザインに合わせる（ちぎれ紙・マステ・マゼンタのタブ）
- [x] 3つの `[data-reserve]` から開くよう `script.js` を変更
- [x] `styles.css?v=N` / `script.js?v=N` を上げる
- [x] 新しい漢字が入るので `python3 tools/build-fonts.py` を流す

## Non-scope

- **店舗ごとの料金表示。** LPが定義しているのは関西2,800 / 関東3,300の2区分だけで、
  名古屋・福岡の額は分からない。推測で置かない。料金は既存の料金セクションに任せる。
- **参考画像の配色の踏襲。** 黒地＋金は却下済みの方向性。構成だけ借りる。
- 予約導線そのものの変更（LINE以外の手段を増やす等）。

## Constraints

- **参考画像は別商材のもの。** 「28歳以上の男性限定」「月〜木2,800/金3,300」は
  over28のLPの条件で、Y2Kのものではない。**文言・条件を持ち込まない。**
- **各店のLINE URLを知らない。** `TODO(店舗確認)` にし、埋まるまでは現行の公式HPへ
  フォールバックさせる。**偽のリンクを置かない。**押しても何も起きない導線は、
  ダイアログが無いより悪い。
- **固定予約CTAは AGENTS.md の「触らない」に入っている。** 依頼を受けての変更。
- 却下済み: 真っ黒の地、紫、大量のシール、意味の通らない英字。
- 書体は3つだけ。セルフホストのサブセットにない字は化ける。

## Result

3か所の予約CTAから店舗選択ダイアログが開くようにした。エリア2タブ（関西・名古屋・
福岡 / 東京）で絞り込み、店舗ごとの公式LINEへ飛ぶ。参加は**全9店舗**。

### 見た目の経緯

最初はちぎれ紙だけで組んだが、依頼を受けて「ガラケー」方向を検討した。**筐体ごと
出す案はラフで測って落とした**: 装飾が248px占め、店舗行が21px、店名11pxまで潰れて、
SPでは更に縮む。**予約導線に置くUIとして成立していない。**
`lp-cvr-knowledge.md` の「一目で理解できるレイアウト」に反する提案だった。

採ったのは、寸法は紙版のまま（行71px / ボタン44px / 店名16.8px）で、ガラケーの記号を
**液晶の帯と発信キーの緑の2箇所だけ**に置く形。筐体・キーパッド・ドット書体は入れない。
4書体目も不要になった。

開く動きは下辺をヒンジに `rotateX(72deg → 0)`。上辺ヒンジで作った初版は蓋が閉じる側の
動きだった。演出は440msに収め、**動作中も押せる**（60ms時点で `pointer-events: auto`）。

### リンクは同一タブ

`target="_blank"` を付けない。このLPは広告流入で Instagram / LINE のアプリ内ブラウザで
開かれ、**あの種の WebView は `_blank` を黙って落とす。**押しても何も起きない導線に
なるより、LPを離れる方がまし。予約はここで完了する。

### 検証の結果

| 検証 | 結果 |
| --- | --- |
| 全9店の実クリック遷移 | 9/9 が LINE 公式アカウントへ到達（6アカウント。関西3店・名古屋2店は共用） |
| 寸法（PC / SP） | 行70px・ボタン44px。44px下限を満たす |
| 画面内・横スクロール | 収まる / なし（1440 / 390 とも） |
| タブ切替・Esc・背景クリック | 動作。body の overflow も復帰 |
| `prefers-reduced-motion` | アニメーション0件。開閉は機能 |
| フォントサブセット | `document.fonts.check` で全店名を照合、取りこぼし0 |
| 回転の角度推移 | 72→45→24→12→5→0（単調。停留なし） |

### 残っている risk

- **関西3店・名古屋2店が同じLINEに飛ぶ。**公式HPも同じ作りなので仕様として正しいが、
  店を選ばせた意味は薄い。エリア1行にまとめる選択肢はある。
- **いただいたLINE URLと公式HP掲載のURLが1本も一致しない。**指示に従いいただいた分を
  使った。公式HPが古いのか別アカウントなのかは未確認。
- `対象店舗` を「公式HPでご確認ください」から「全9店舗（予約時に選択）」に変えた。
  **9という数はダイアログの実装と一致させただけで、店舗側の確認は取っていない。**
- 閉じるアニメーションは無い（開くときだけ）。畳む動きは付けていない。
