## なぜ汚かったのか（実測）

PC 1440 で `.event-sheet` は 1052×340。紙の内側は 984px あるのに、
**中身は見出し1行と dt/dd が2行だけ**で、ほぼ空白の帳票に見えていた。

さらに `.event-sheet .event-list > div` が
`grid-template-columns: 108px minmax(32px, 1fr) minmax(190px, 280px)` で
**値の列を固定幅にしていた**ため、リーダーの点線は 836px で終わるのに
値は 969px から始まり、**133px の空白が開いて点線が切れて見えていた。**

**もう1つ、こちらが作った問題がある。**予約ダイアログを伏せた結果、
**9店舗がページのどこにも出なくなった。**「全9店舗」とだけ書いてあって、
どの店か分からない状態だった。

## Goal

節が「開催店舗」になり、**9店舗の名前が実際に読める。**
紙に空白の帳票感が無く、PC で5列（エリアごとに1列）が1行に収まる。

## Result

**実装済み（2026-11-17）。** `styles.css?v=485`。`script.js` は触っていない。

### 判断

**点線を直すのではなく、組み方ごと替えた。**値の列を `auto` にすれば点線は
つながるが、**項目が2行しか無い以上、紙は空のままだった。**原因は列幅ではなく
中身の量なので、中身を入れた。

**列は `repeat(auto-fit, minmax(172px, 1fr))`。**最初 186px で書いたら
`5*186 + 4*18 = 1002px > 984px` で4列に落ち、**東京だけ2段目に回って段が揃わなかった。**
172px なら `5*172 + 4*16 = 924px` で5列が収まる。SPでは自動で2列になる。

### 踏んだこと

**店名の後ろに付けた `※` が、390px で1文字だけ次の行に落ちた。**
注記が店名を名指ししているので印は不要と判断し、インラインの `※` を外した。

**注記が「（残 / 数限り）」と熟語の途中で割れた。**390px で実測。
`.venue-note b { display: inline-block }` で、折り返さない単位を作って回避した。
**`b` に意味は持たせていない。**

### 検証

```
             320    375    390    768    1440
押せる予約ボタン  0個   0個   0個   0個   0個
横スクロール     =     =     =     +2px  =     ← 768は既知（.tape--y.tape--r1）
JSエラー        0件   0件   0件   0件   0件
```

- PC 1440: 紙 1052×394、リスト 984×131、**5列**、紙の下の余り 0px
