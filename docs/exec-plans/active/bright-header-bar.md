# ヘッダーバーを明るくする

- **Started:** 2026-09-01
- **Rule:** [AGENTS.md](../../../AGENTS.md)
- **Completed path:** `docs/exec-plans/completed/bright-header-bar.md`

## Goal

固定ヘッダーの暗いグレーの地をやめ、Y2K当時のウェブUIを参照した
明るいミルキーグラデーションにする。

## Scope

- [x] `.bar` の地を水色→桃→藤→クリームのグラデに差し替え
- [x] 下辺にキャンディ罫（ピンクと水色の破線）を足す
- [x] ロゴの白抜きが飛ぶので、墨版 `asobibar-logo-ink.svg` を作って
      ヘッダーだけ差し替え
- [x] タグ・ノンブルの文字色を明るい地に合わせる
- [x] フッター（地が暗い）はロゴを白抜きのまま、タグは水色に戻す

## Non-scope

- 参考画像にあった上段のお知らせ帯（載せる情報がなく、高さだけ増えるため不採用）
- フッターの地の色

## Constraints

- 濃い紫を使わない（`no-violet` が #2b1641 系を機械判定でブロックする）
- 明るいバーは明るいセクションの上に来ると境界が消えるので、
  必ず下辺で切る
- ロゴのSVGは白抜き前提。明るい地に置くと文字が消える

## Acceptance

- [x] ヘッダーの文字とロゴが、表紙（暗い写真）と03（クリームの紙面）の
      どちらの上でも読める
- [x] フッターのロゴが暗い地の上で消えない
- [x] `no-violet` を通る

## Verification

- [x] `node scripts/harness/harness-check.mjs`
- [x] `node tools/verify/health.mjs`
- [x] PC 1440 / SP 390 で、表紙の上と03の上のキャプチャを目視

## Result

- harness-check: 機械判定はすべて pass。
- health.mjs: `docH 9260` / JSエラーなし / 読み込み失敗なし /
  グリフ1230字を検査して欠けなし。
- キャプチャ: 表紙（暗い写真）・03（クリーム）のどちらの上でも
  ロゴとノンブルが読めることを確認。

判断したこと:

- 地が不透明になったので `backdrop-filter: blur()` は効かない。外した。
- 参考画像は上段のお知らせ帯＋下段の本体という2段構成だが、載せる情報が
  ないなら帯は高さだけ増えて何も運ばない色の線になる。1本のままにした。
