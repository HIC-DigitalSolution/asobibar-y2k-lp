# 05の店舗選択を、エリアタブ＋店舗カードにする

- **Started:** 2026-11-17
- **Rule:** [docs/design-docs/lp-cvr-knowledge.md](../../design-docs/lp-cvr-knowledge.md) §5

## 依頼内容（2026-11-17）

> 一番予約しやすいレイアウトとUIデザインはどんなものがいいと思いますか？
> → （途中）ダイアログとか使ってエリアごと分けてもわかりやすい
> → **https://halloween-lp.hic-marketing.com/ のハロウィンLPの店舗のやつ見て、あんな感じを理想としてます**

## 理想形（実物を見て採寸）

ハロウィンLPの `RESERVE`:

```
対象の店舗　9店
[関東 3店] [中部 2店] [関西 3店] [九州 1店]   ← ピルのタブ。選択中は塗り
┌────────────────────────┐
│ [写真] 新宿歌舞伎町タワー前店              │
│        [LINEで予約(緑ベタ)] [03-6709-6274]│
└────────────────────────┘
```

- **ダイアログに畳まない。**タブで絞って、その場に出す
- 各タブに**件数**が入る
- カードは **写真（左）＋店名＋LINE緑ベタ＋電話番号（白地に枠）**
- エリアは **関東 / 中部 / 関西 / 九州 の4つ**（公式の5エリア区分とは別）

## Goal

**この骨格を、Y2Kの紙の言語で再現する。**押せる形（§5）を満たし、
JSが落ちても一覧が出る。

## Scope

- [x] `.venue-pick` を新設（総数 → エリアのピルタブ → 店舗カード）
- [x] エリアを4つに再編（関東3 / 中部2 / 関西3 / 九州1 = 9）
- [x] 切り替えを **radio + 兄弟セレクタ**で実装（JSなし）
- [x] 電話番号を追加（公式サイトの実データ）
- [x] 旧実装の残骸を削除（`.event-list` / `.venue-list` / `.venue-areas`）
- [x] 重複した文言を削除（「予約方法」、導入文の「9店舗」）

## Non-scope

- **予約ダイアログ（`.storepick`）は触らない。**固定CTAからの導線は従来どおり。
  05は「店が決まっている人の近道」、ダイアログは「決まっていない人」用。
- イベント名の不一致（交流上等/マッチ上等）は依頼者の指示で触らない。

## Constraints

- **緑のベタを使えるのはタブのおかげ。**画面に出るのは最大3個。
  9個並べると紙の中で彩度がCTAを超える（`lp-visual-knowledge` §2）。
- **radio は DOM の先頭にまとめる。**`~` で後ろのタブとパネルを掴んでいる。
  **順番を入れ替えると切り替えが死ぬ。**
- 電話番号・店舗名・LINE URL はすべて実データ。推測しない（`no-invented-store-facts`）。
- 押せる高さ 44px を切らない。

## Acceptance

- [x] タブ4つ、件数つき。押すとそのエリアだけ出る
- [x] カードに 写真 / 店名 / LINE / 電話
- [x] LINEの行き先が `.storepick` の9件と一致
- [x] ボタンが44px以上、SPでも1段に収まる
- [x] JSエラー0件／横スクロールの増加なし
- [x] **JSを切っても一覧が出る**（radio + CSS のみ）

## Verification

- [x] `node scripts/harness/harness-check.mjs`
- [x] ヘッドレスChromeでタブ切り替え・寸法・1段判定
- [x] PC・SPのスクリーンショット目視

### 追記2（同日）— PCのレイアウトを直し、新宿の注記を戻した

**依頼者の指摘: 「中のレイアウトがかなり悪いな」**

実機ペインで見てもらって判明。**PCでカードを1列（全幅984px）にしていたため、
中身は左の4割（写真112px＋店名＋ボタン）だけで、右6割が空いていた。**
電話番号を外したぶん、さらに空いた。**SPばかり見て、PCの絵を確認していなかった。**

| | 前 | 後 |
| --- | --- | --- |
| PC | 1列・横組み（写真左） | **3列・縦組み（写真上）** |
| カード | 984×約110px | **317×274px** |
| 写真 | 112×84px | **297×167px** |
| 右の余り | 約590px | **10px** |
| SP | 1列・横組み | **変更なし**（1枚112pxでは店内が判別できない） |

**`auto-fit` は使わない。**九州が1店なので、1枚が984pxまで伸びて元に戻る。
`repeat(3, minmax(0,1fr))` で固定し、1店のときもカード幅を他エリアと揃えた。

**新宿の注記を入れ直した（依頼者の指示）。**

> ※ 新宿歌舞伎町タワー前店はイベント自体は終了で、Y2Kの文化のみ、
> チェキの残数がなくなるまで、チェキとリクエスト券は続行しております。

**文面は依頼者の言葉から変えていない。**店名だけ、ページ内の他の表記に合わせて
正式名称にしている（依頼者は「新宿店」と書いていた）。
**一覧の外（カードの下）に置く。**カードの中だと対象店に見える。

### 追記3（同日）— SPも縦組みにした

**依頼者の指摘: 「SP表記でも気になるんだよね」**

PCを直した直後に、SPも見てもらって判明。横組み（写真が左）のままで、
**写真が 104×78px しかなく、店内が判別できなかった。**
写真を足した目的（選べるようにする）が果たせていない。
さらに緑のボタンが写真より目立ち、右側に死んだ余白が残っていた。

| | 前 | 後 |
| --- | --- | --- |
| 組み方 | 横（写真が左） | **縦（写真が上・全幅）** |
| 写真 | 104×78px | **306×172px** |
| カード | 322×94px | 322×242px |
| 右の余り | 101px | **8px** |

**店名とボタンは写真の下に1行で並べる**（名前が左・ボタンが右）。
縦に積むと右側がまた空く。

**1列でも長くならない。**タブで最大3店に絞っているので、関西（3店）で約730px。

注記の折り返しも直した。`Y2Kの文 / 化のみ` と熟語の途中で割れていたので、
`<b>` で折り返さない単位を3つに分けた。

**PCとSPは別々に目で見ること。**今回はPCを直してSPを見ておらず、
その前はSPを直してPCを見ていなかった。**2回とも依頼者に指摘されている。**

### 追記4（同日）— 幅を刻んで測り、列数を3段にした

**依頼者の指摘:「このはばが気になる／右側空きすぎ」**（約550px幅の画像つき）

いただいた画像は直す前の横組みのものだったが、**幅を13点刻んで測ったら
別の穴が見つかった。**SPを1列にしたせいで、**480〜767pxでカードが
666×436px・写真が650×366pxまで肥大**し、1店が画面を占めていた。
**1点の幅でしか確認していなかったのが原因。**

列数を3段にした。

| 幅 | 列 | カード | 組み方 |
| --- | --- | --- | --- |
| 〜519px | 1列 | 292〜440px | 写真の下に **店名とボタンを横1行** |
| 520〜899px | 2列 | 213〜390px | 写真の下に店名、その下にボタン |
| 900px〜 | 3列 | 247〜317px | 同上 |

**3列は900pxから。**768pxで切り替えると1枚209px・写真189×106pxまで縮む。
900px はこのページがPCと見なす境目（`.cover__info` と同じ）。

**520px以上で横1行をやめたのは、`名古屋栄錦通り / 店` と店名が割れたため。**
2列では名前の列が狭い。13幅すべてで店名が1行に収まることを実測で確認した。

**`auto-fit` は使わない。**九州は1店なので、1枚が984pxまで伸びて
「右が空きすぎ」に逆戻りする。

### 追記5（同日）— タブの件数を外し、店名を20px下げた

**依頼者の指示:**

> ボタンも2店とかいらないです
> というかそんなに小さな文字入れても読めないです
> 渋谷横丁前店とか店名の箇所の左を20pxほど開けて置いてください

- **タブの件数（`2店` など）を4つとも削除。**10.5px は実際に読めない大きさだった。
  **ハロウィンLPから「件数つきのタブ」を取ったが、あちらは本文が大きく、
  同じ要素でも読める。装置だけ持ってきて寸法を合わせていなかった。**
  件数は上の `.vp__total`（対象の店舗 8店）が持っているので、情報は落ちていない。
  タブは `grid`（2段）→ `inline-flex`（1行）に変更。高さは44pxのまま。
- **店名とボタンの塊に `padding-left: 20px`。**写真は断ち落としのまま、文字だけ内側へ。
  **店名だけ下げるとボタンと頭が揃わない**ので、`.vp__body` ごと下げている。

11幅すべてで、タブ44px・インデント20px・店名1行を実測で確認。
