セクションごとの作り込みで後から書いた次のルールに負けていた:

**`#last-title` だけ効いていたのは ID (1,0,0) だったから。偶然。**

**「当てた」と「効いている」を確かめずに報告していた。**D案の Result に
「39/141 テキストノード」と書いたが、あれは**当たった数**であって、
どの見出しに効いたかは見ていない。**次からは適用後に computed style を読む。**

### 直し方

依頼者の選択は **A（ドットに統一）**。`!important` は使わず、
**ファイル末尾で同じセレクタを書き直して**勝たせた。important を撒くと
次にここを触る人が理由を追えなくなる。

- **`font-size` は各セクションのまま残した。**サイズの緩急は意図したもので、
  揃えると全セクションの版面が動く
- **`letter-spacing` は上書きした。**元は -0.045em〜-0.06em の詰めで、
  ドットは字面が小さいぶん詰めるとドット同士がぶつかる。`0.005em` へ
- **`font-weight` は 400 に落とした。**900 のままだと合成ボールドで潰れる

### 検証（SP 390×844 / PC 1440×900）

**6つの節見出しが全て DotGothic16 / 400。**`.howto-title`（英字ロックアップ）と
`.mix-telop`（テロップ帯）は別の記号なので当てていない。

写真の上に載る見出しの実ピクセル比（`el.screenshot()` で切り出し、
暗い側10%と明るい側10%の輝度比）。**ドットは400しか無く線が細いので測り直した:**

| | SP | PC |
| --- | ---: | ---: |
| `#request-title` | **4.99** | 5.04 |
| `#karaoke-title` | 6.10 | 6.09 |
| `#price-title` | 6.47 | 6.91 |
| `#last-title` | 13.74 | 20.41 |
| `#cheki-title` | 15.75 | 15.96 |

**いちばん薄いのが 4.99。**AA本文の 4.5 を満たす。大字（32〜59px）なので
基準は 3.0 で、そちらには余裕がある。折り返し行数・はみ出し・横スクロールも再確認して変化なし。

**測り方で1つ踏んだ:** `boundingBox()`（ビューポート基準）を `screenshot({clip})`
（ドキュメント基準）に渡して、**別のセクションを切り出していた。**
数字は出るが中身が違う。`elementHandle.screenshot()` を使えば起きない。
