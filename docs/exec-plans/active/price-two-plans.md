- **Rule:** [docs/design-docs/lp-cvr-knowledge.md](../../design-docs/lp-cvr-knowledge.md)（外部リンクの最小化 / 簡潔で理解しやすいビジュアル表現）

## Goal

05プランが**1プラン1価格表**から**2プラン**になる。U-25 と OVER28 を、
どちらが自分向けか一目で分かる形で並べ、**今まで無条件の「100分プランの料金」に
見えていた 2,800/3,300 が OVER28 の料金であることが読めばわかる**状態にする。

## 依頼内容（2026-09-14・小林寛さん）

> U-25 / OVER28 プランを追加。9月末まで。
>
> U-25 100分プラン｜日〜木曜限定｜関東以外 2,500円(税込)／関東 3,000円(税込)
> OVER28 100分プラン｜内容 https://asb-over28-campaign.hic-marketing.com
>

## 事実の出どころ

**推測で埋めない**（`no-invented-store-facts`）。今回の数字と条件は2つの出所しか無い。

| 事実 | 出どころ |
|---|---|
| U-25 の曜日・エリア別価格・9月末まで | 依頼文（上）**のみ** |
| OVER28 の対象・曜日・エリア別価格・期間 | 公式キャンペーンLP https://asb-over28-campaign.hic-marketing.com を実機で読んだ値 |

OVER28 の実測（2026-09-14 時点、同ページ本文より）:

- 28歳以上の**男性**限定・**月〜金**限定（土日は対象外）
- 期間 2026年8月20日(木)〜9月30日(水)
- 関西・名古屋・福岡：月〜木 2,800円／金 3,300円（税込）
- 東京：月〜木 3,300円／金 3,800円（税込）

**現行LPの「関西 2,800／関東 3,300」は、この表の月〜木の行**だった。
エリア名も「関西」では福岡・名古屋を落としている。予約ダイアログのエリアは
神戸・大阪・名古屋・福岡・東京の5つなので、**「関東以外」が5エリアに対して正しい**。
依頼文の U-25 も「関東以外」表記なので、2プランで表記が揃う。

## Non-scope

- **見出し「100分プラン誕生！」は変えない。**2プランになっても文として成立し、
  コピーの変更は依頼に無い。
- **キャンペーンLPへの外部リンクは足さない。**CVRナレッジの「外部リンクの最小化」。
  URLは事実の出どころとして使い、条件はこのLPの中に書く。既存の
  「料金・プランを詳しく見る」→公式HP は残す。
- **U-25 の年齢定義・性別・対象店舗は書かない。**依頼文に無い。
  「U-25」は依頼文の表記のまま出す。
- 予約ダイアログ（storepick）は触らない。プラン別の店舗が不明なため。

## Constraints

- `data-count` のカウントアップは4つに増える。JSは `[data-count]` を
  インデックス90ms刻みで回すだけなので増えても動くが、実機で確認する。
- `.price-panel .plan-prices dd` は `clamp(2.55rem, 4.4vw, 4rem)`。
  2プランぶん縦に積むと画面を食うので、**数字の大きさを落とす前に
  カードの並べ方（PC横並び／SP縦積み）で吸収する。**
- 色を増やさない（`lp-visual-knowledge.md` §アクセントは2色だけ）。
  プラン名の区別に新しい色を使わない。既存のシアン／ピンクの菱形と墨だけで組む。
- 装飾を足さない（同 §読ませたい場所に世界観を持ち込まない）。ここは読ませる場所。

## Result

**実装済み（2026-09-14）。**`index.html` 05節と `styles.css`、`styles.css?v=474`。

### 決めたこと

- **PCは横2枚、SPは縦2枚。**数字は `clamp(1.75rem, 2.6vw, 2.6rem)` まで落としたが、
  これは「2枚並べたから」ではなく**1枚あたりの幅が半分になったから**で、
  1枚あたりの数字の見えの大きさは変えていない。
- **プラン同士は実線、プランの中のエリア区切りは破線。**最初どちらも同じ破線で組んだら、
  実測のスクリーンショットで**4つの金額が横一列に見えて、どれが同じプランか読めなかった。**
  線の意味を2つ使うなら、太さか実線/破線を変える必要がある。
- **`subgrid` で2枚の金額の高さを揃えた。**768px前後で OVER28 の条件だけが2行に折り返し、
  金額の行が38pxずれていた（実測）。カードを独立した箱にしたままでは直らない。
- **条件の一行を注記に逃がさなかった。**「2,500円」だけが読まれて「日〜木曜」が
  伝わらないのがいちばん困る。名前のすぐ隣、金額の真上に置いた。
- **色は足していない。**菱形のシアン＝関東以外／ピンク＝関東は2枚で共通なので、
  同じ色が同じエリアを指す。

### 検証（ヘッドレスChrome / http://127.0.0.1:8899）

```
幅      320  375  390  768  1024  1440
はみ出し  0    0    0    0    0     0
```

- **金額の高さ揃い**: 2枚の差は 1.2〜2.1px。これは紙（sheet）自体が
  わずかに傾けてあるぶんで、幅に比例して増える。紙の座標系では揃っている。
- **横スクロール**: 読み込み直後 320/375/390/1024/1440 は増加なし、768 のみ 770px。
  **これは変更前の HEAD でも同じ 770px**（`git archive HEAD` を別ポートで並べて比較）。
  既知の `.tape--y.tape--r1` で、今回とは無関係。
- **コントラスト**（紙の実ピクセル rgb(247,241,236) を採取して計算）:
  条件 `#b0175e` **5.99** ／ 注記・「100分プラン」 `#6d635e` **5.21** ／
  墨の金額・エリア名・プラン名 **15.46**。いずれもAAの4.5以上。
- **カウントアップ**: 4つとも最終値（2,500 / 3,000 / 2,800 / 3,300）で停止。
- コンソールエラー・リクエスト失敗 0。
- `python3 tools/build-fonts.py` 再生成。562字 / 332.1KB（前 551字 / 323.6KB）。
- `node scripts/harness/harness-check.mjs` 機械判定すべてpass。

### 依頼者に確認して埋めたもの（2026-09-14）

- **U-25 は「25歳以下」。**条件を「25歳以下・日〜木曜限定」に直し、
  OVER28 の「28歳以上の男性・月〜金曜限定」と同じ形に揃えた。
- **性別の限定は OVER28 だけ。**U-25 には書かない、で確認済み。
  **片側だけ条件が厚いのは事実どおりで、揃え忘れではない。**

- **期間は2プランとも出す**（2026-09-14に確認）。U-25 は **9.1〜9.30**、
  OVER28 は公式キャンペーンLPどおり **8.20〜9.30**。
  **このLPの開催期間（9.7〜9.30）とは別の日付が出ることを確認したうえでの決定。**
  06開催情報・固定CTAバー・予約ダイアログの3か所は 9.7 のまま。
- **26〜27歳がどちらのプランにも当てはまらない件は「このままでいい」**で確認済み。

- **19歳からの入場は神戸三宮店のみ**（2026-09-14に依頼者から）。注記に出した。
  **他店の下限が何歳かは聞いていないので書いていない。**「三宮だけ19歳」という
  事実からは「他店は19歳では入れない」までしか言えず、20歳なのか21歳なのかは別の話。
  年齢制限を推測で埋めると、そのまま店頭でのトラブルになる。
  注記の中でこの一文だけ墨（`.paper-note b`）にしてある。読み落とすと
  現地で断られる種類の情報なので、他の注記と同じ濃さにしない。
