## Result

**実装済み（2026-09-30）。**`styles.css?v=483` / `script.js?v=76`。

### 判断

- **`hidden` 属性＋`[hidden]{display:none!important}` で伏せた。**
  UAの `[hidden]` は作者スタイルに負けるので、CSSが無いと
  **属性だけ付いて表示は残る**という一番厄介な壊れ方をする。
- **ノンブルは属性で判定する。**`display:none` の要素は
  `getBoundingClientRect()` が全部0を返すため `top <= mid` が常に真になり、
  伏せた節の番号が出る。`!s.hidden` ならレイアウトに依存しない。
- 戻し方は `index.html` の `#price` の直前にコメントで4項目（+1）書いた。

### 踏んだこと

**`data-page` だけ直して、誌面に印刷されている番号を直し忘れた。**
ヘッダのノンブルが P.05 なのに本文が「06 — 開催情報」になっていた。
スクリーンショットで気づいた。**機械の検証は全部通っていた**（番号の整合は
どの契約も見ていない）。開催情報 `<b>06</b>`→`<b>05</b>`、予約 `<b>08</b>`→`<b>07</b>`。
