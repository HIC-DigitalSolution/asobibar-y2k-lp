- **Started:** 2026-11-17

## 依頼内容（2026-11-17・小林寛さん）

> Y2KのLP／CTAと詳細から、期間を排除しといてください！

スクリーンショットで丸が付いていたのは2か所。**固定CTAバーの小文字**（「10月末まで・席数限定」）と、
**05 開催情報の見出し＋日付**（「9月7日から、10月末まで」／「2026.9.7 — 10.31」）。

同じメッセージで店舗の現況も共有された:

> チェキとリクエスト券は続行しております。

`10月末` `9.7` `10.31` `9月7日` `10月31日` が表示文字列に0件。
終了日を持たないページとして読め、**05が見出しを失って空にならない。**

### 判断

**05の見出しは「期間そのもの」だった。** 消すと `<h2 id="event-title">` が空になり、
節の `aria-labelledby` が宛先を失う。利用者が3案から `Y2K NIGHT、開催中。` を選択。

**新宿に注記を入れた。** 期間を外すと「全店で開催中」に読めるが、新宿だけ本編が
終了している。利用者が「注記を入れる」を選択。**文言は依頼者のメッセージから
外していない**（`no-invented-store-facts`）。**公開前に小林さんの確認が要る。**

**`券` が収録外の漢字だった。** `python3 tools/build-fonts.py` を流して6本とも
焼き直し（565字 / 合計 334.6KB）。流さなければその字だけ別書体に化けていた。

### 踏んだこと

**注記を `.storeline__name` の中に `display: block` で置いたら、375px で
「チェキ・リクエスト券のみ（残 / 数限り）」と熟語の途中で割れた。**
名前の列が 220px しかないため。`flex-basis: 100%` ＋ `order: 3` でカード幅
いっぱいの行へ送り、1行で収まるようにした。

**`.storeline` に `flex-wrap: wrap` を足すのは、あのブロックの注意書きに触る。**
過去の事故は「長い店舗名がLINEボタンを下へ落とす」こと。名前は `min-width: 0`、
ボタンは `flex: 0 0 auto` なので1行目は従来どおり分け合い、実測でもボタンは
44px のまま動いていない。`row-gap` を 12px→7px に詰めて、注記が同じカードの
文に見えるようにした。
