# 単語からジャンルを推測して、参考の実物を見なかった

- **踏んだ日:** 2026-09-04

## 症状

依頼者「**ヤンキー漫画じゃないけど**」。

その前に依頼者が言っていたのは「**ラブ上等というネトフリの作品のパロディ感のあるデザインに
したい**」で、私はその作品を見ないまま実装していた。**「上等」という語だけから
「特攻服 → 金の刺繍 → ヤンキー漫画」と決めつけていた。**

推測の上に載っていたもの:

- `.mix-logo` の**金の二重縁取り・詰めた字間・傾き**（「特攻服の刺繍の見え方を借りる」）
- **Reggae One という書体選び**と、そのサブセット（「交流上等」4字）
- **`--font-yankee` という変数名**
- 節全体の墨紫・金・オレンジという配色

実物は**写真主体のキーアート**だった。色の違う2つの部屋を継ぎ目で突き合わせ、
その上に中央寄せの文字段が小さく積んであるだけ。**金の刺繍も、傾いた字も、1つも無い。**

## 原因

**参考にしているものを1度も見ずに、単語からの連想を根拠として扱った。**

依頼者は最初から作品名を出していた。画像を頼めばよかっただけで、
**推測しなければならない場面ではなかった。**

さらに悪いことに、その推測は**コードのコメントとして自信ありげに書かれていた**
（「特攻服の刺繍の見え方を借りる」）。次に読む人には、これが**調べた結果**なのか
**思いつき**なのか区別がつかない。

## 直したもの

- `index.html` の `#mix` — キーアート（左右/上下の分割＋中央の文字段）に組み直し
- `styles.css` の MIX ブロック — `.mix-logo` の刺繍表現を削除
- **Reggae One を全部削除** — `@font-face` / `--font-yankee` /
  `tools/build-fonts.py` の行 / `assets/font/reggae-400.woff2`
- 経緯と実測は
  [docs/exec-plans/active/mix-band-section.md](../exec-plans/active/mix-band-section.md)

## 次から

**参考にしている実物を見るまで、ジャンルを決めない。** 作品名・店名・商品名が出たら、
**画像を1枚もらう。**「たぶんこういう系」で手を動かし始めない。

**推測でやったことは、推測だと書く。** コードコメントに「〜の見え方を借りる」と書くなら、
**何を見たのか**を書く。見ていないなら「未確認」と書く。**断定的なコメントは、
次の人がそれを検証済みの事実として扱う。**

**これは順序の gotcha と同じ形です**
（[section-order-benefit-before-price.md](./section-order-benefit-before-price.md)）。
どちらも**機械の検証が全部通っている状態で間違えている。**
`harness-check` は「参考に似ているか」を見られない。
